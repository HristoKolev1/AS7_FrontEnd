# Enterprise E-commerce Frontend

Frontend application for the **Enterprise E-commerce Platform**.

The application provides the user interface for interacting with the platform's independent backend services, including users, products, shopping carts, orders, and payments.

## Features

- User-facing e-commerce interface
- Product browsing
- Shopping cart interaction
- Ordering workflow
- Integration with the platform's backend services

## Tech

React · TypeScript · REST APIs

## Backend Services

- [User Service](https://github.com/HristoKolev1/AS7_UserService)
- [Product Service](https://github.com/HristoKolev1/AS7_ProductService)
- [Shopping Cart Service](https://github.com/HristoKolev1/AS7-ShoppingCart)
- [Order Service](https://github.com/HristoKolev1/AS7_OrderService)
- [Payment Service](https://github.com/HristoKolev1/AS7Payments)

## Project Context

The application was developed as part of a university software engineering project focused on designing and implementing a complete e-commerce system using independently developed services.
